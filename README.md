# `@dsh/ui-design-guide`

DeepSeek Harness 插件：让 AI 从 UI 设计图生成“设计图解析结果 / 人工描述提示词”，再经过用户澄清和控件复用确认后实现界面。

人工描述提示词不是插件的前置输入，而是 AI 根据设计图生成的第一阶段输出。

## 功能

- 以设计图、截图和用户当前消息为主要输入，不要求目录中预先存在人工描述词。
- 要求 AI 先读取图片和项目代码，并区分可观察事实与待确认内容。
- 先输出完整的设计图解析/人工描述提示词，再进入实现阶段。
- 将设计图拆分为主窗口、状态窗口/状态变体、控件样式参考、可复用控件和数据绑定。
- 要求 AI 搜索项目内已有控件；候选不明确或控件缺失时使用 `ask_user_question`。
- 覆盖并排窗口、转入/转出变体、完成/未完成/禁用/悬停状态、滚动区域和接口字段映射等常见歧义。
- 在改代码前输出设计解析结果、复用决策、状态表、数据映射、风险和验证清单。

## 安装

在目标 profile 目录执行：

```text
dsh plugin --profile web add link:D:/AI/ui-design-guide-plugin
```

安装后重启 DSH Web。插件仅加入 system prompt，不修改 Web UI，也不执行设计资料中的命令或接口请求。

## 本地验证

